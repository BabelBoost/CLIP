# Praktyczna Biblioteka: outro 1080 × 1920

Pobierz Praktyczna_Biblioteka_Outro.html przyciskiem Download raw file na stronie pliku GitHub. Otwórz pobrany plik w Chrome lub Edge.

Szablon działa lokalnie. Domyślny język: polski. Możesz zmieniać nagłówek, dopisek, CTA, adres i okładkę. Bez okładki wyświetla się uniwersalna grafika książki.

Domyślne teksty:
* Wiedza, która ułatwia życie.
* Praktyczne poradniki na co dzień.
* SPRAWDŹ EBOOKI
* naffy.io/praktyczna-biblioteka

Eksport PNG lub 6 sekund WebM bez dźwięku. Podczas eksportu pozostaw kartę aktywną. Dodaj wynik na końcu reklamy. W razie potrzeby przekonwertuj WebM do MP4 w edytorze wideo.

Zachowano układ i kolory szablonu Babel Boost. Nie jest to odtworzenie identyfikacji wizualnej sklepu Naffy. Strona sklepu była niedostępna do odczytu.

Sprawdzono składnię JavaScript, rozmiar canvas i zamianę marki. Podgląd oraz eksport w przeglądarce nie zostały zweryfikowane w tym środowisku.
